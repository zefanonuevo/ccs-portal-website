# Security policy

## Reporting a problem
Please report a security problem **privately**, not as a public issue.

Open this repository's **Security** tab, choose **Report a vulnerability**, and describe what you found and how to see it. Do not include real people's emails or passwords. The maintainer is the Technical Support Staff of the DLSU-Manila College of Computer Studies.

## What is in scope
The CCS Commons portal at https://ccs.dlsu.edu.ph: the pages in this repository and the sign-in server in `server/`. The Student Grants site at `/scgss/` is a separate repository (`ccs-scgss`).

## What to expect
Reports are read by one person and answered as soon as possible. There is no bug bounty.

## Good to know
- No page content is protected yet: everything in the pages is public by design (see [README.md](README.md)).
- How the server defends sign-in, and what is accepted or still open: [server/README.md](server/README.md) and [docs/Architecture.md](docs/Architecture.md) section 2.3.
